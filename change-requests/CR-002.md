**Status:** Done

## Mål

Implementere brukervendt mobilapp med hjemskjerm, fordelsliste og fordelsdetalj.
Første fase med faktisk innhold fra databasen.

---

## Scope

### Inkludert
- Hjemskjerm: HeroCarousel + fordelsgrid
- Fordelslisteside `/benefits` med kategorifilterkort
- Fordelsdetaljside `/benefits/[slug]` med redemption
- Redemption-typer: `generic_code` (vis + kopier), `external_link`, `lead_form` (grunnleggende), `info_only`
- Hendelseslogging via `/api/track` (fire-and-forget)
- Lead-innsending via `/api/benefits/[slug]/lead`

### Ikke inkludert (utsatt til Fase 3)
- Autentisering og brukersesjoner
- Lagrede fordeler (Mine fordeler)
- Nær deg / postnummer-targeting
- Unik kode-tildeling (atomisk)
- QR-kode-visning
- PWA-ikoner

## Arkitekturnotat

- Sider (Server Components) henter data direkte via `lib/queries/` — ingen API-hop
- Client components: `HeroCarousel`, `CategoryFilter`, `RedemptionSection`
- `isSaved` er hardkodet `false` frem til autentisering implementeres i Fase 3
- Targeting ikke implementert i demo — alle aktive fordeler vises for alle brukere
